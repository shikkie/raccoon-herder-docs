Architecture

Raccoon Herder is a chat control plane. The browser never owns a TTY. The daemon owns sessions; agents are child processes.

Components

flowchart LR
  phone[PWA / browser]
  web[web proxy :42069]
  daemon[daemon :42070]
  agent[ACP CLI stdio]
  herder[Herder]
  den[Den container]

  phone --> web --> daemon --> agent
  herder -->|create / stop / open| den
  den --> daemon
Piece Role
PWA Chat UI. Same-origin /api and /ws.
Web proxy Serves the built SPA and proxies to the daemon on loopback. Default :42069 (host) or :8080 (den).
Daemon Sessions, transcripts, workspace IO, ACP (or PTY fallback). Default :42070.
Agent grok, claude, copilot, hermes, or generic (sh).
Herder Separate binary (herder/). Spawns dens. Not inside daemon/.
Den One isolated copy of the whole stack + a workspace.

ACP-capable CLIs speak JSON-RPC on stdio. Raw PTY is a debug escape hatch, not the product UI.

Host vs den vs Herder

    pwaH --> webH --> dH
  end
  subgraph manyDens [Many users]
    herder[Herder]
    denA[Den A]
    denB[Den B]
    herder -->|token + ENV + image| denA
    herder --> denB
  end
  denA -.->|must not reach Herder control plane| herder
  • Host install: systemd --user (or ./dev.sh) for the person who owns the machine. Agent CLIs on PATH. Optional pairing QR on LAN.
  • Den: container image. RACCOON_TOKEN is required. Workspace is /workspace. No LAN discovery. Pairing is off unless --allow-pair.
  • Herder: mints the token, optionally a LiteLLM virtual key, waits for /api/ready, prints an open URL once. Dens do not get docker.sock, a kubeconfig, privileged, host net, or host PID.

Isolation

Each den (and a careful host install) has:

  • its own RACCOON_TOKEN
  • its own RACCOON_CWD (jailed to the workspace in a container)
  • its own state_dir (sessions, transcripts)
  • its own LLM credentials (never logged)

Dens must not reach the Herder control plane. They do not list other dens. Path-prefix multi-tenancy does not work with the current service worker — give each den its own hostname.

Ports and probes

URL Auth Meaning
GET /api/health none Liveness
GET /api/ready none cwd exists and requested agent bins resolve
GET /api/status token Host snapshot
/api/*, /ws token or session cookie Everything else

The PWA talks to the web origin only. In production, terminate TLS on a reverse proxy and bind the app to loopback.
