Using the PWA

The installed app is per origin. Fine for a sticky den; skip for a 20-minute job. Open the den with a one-time ?token= (Herder prints that URL). After login the token is a cookie, not a query string.

Dev HMR: cd web/app && npm run dev (proxies to :42069). Production static is what web/server.py serves.

Sessions

  • Sidebar lists sessions (title, agent, cwd, turn chip).
  • New session / card New here / /rh-new — same agent and cwd, new raccoon id.
  • Resume a stopped session; Join a running one from another device (?session=<id> still needs a token).
  • Resume agent session… — native ACP threads (session/load).
  • Search all sessions from the sidebar; export a transcript as Markdown or JSON.

Status starts as starting, then running, or auth_required until vendor login. Error stays on the card.

Composer and /rh-*

Type / for agent skills. Raccoon-only commands are namespaced so they do not collide:

Command Effect
/rh-new / /rh-clear New session, same agent + cwd
/rh-shell / /rh-sh Local shell in the session cwd (off in dens unless --allow-shell)
/rh-git Den git report (same as the dirty chip)
/rh-models List ACP model ids; /rh-models set <id> applies one
/rh-stop Stop the active session
/rh-delete Delete confirm

Follow-up delivery (queue / steer / send now) is on Sessions.

Approvals and tools

Tool cards show running work. When the agent asks, a sticky Allow / Deny bar appears. Always-allow / always-deny persist on that raccoon session; allow all is session-wide, not a silent host default.

Workspace and git

The workspace drawer browses and inline-edits files under the session cwd (in a den, under RACCOON_CWD). Attachments: paste, file, camera.

The git drawer and header den-dirty chip poll GET /api/workspace/git. Default interval 30s (RACCOON_WORKSPACE_GIT_POLL_S; 0 off). Settings can override in the browser. The Herder uses the same probe before den stop / den rm.

Den buttons

Dens can show extra start/stop buttons (demo todo UI, and whatever you put in den_buttons.json). herder den create --demo is the canned example: PWA on the den web port, Vite todo on host 9998.

/shell, pairing, and generic sh are off in dens unless the Herder passed --allow-shell / --allow-pair / --allow-generic.

Notifications

PWA service worker handles updates. Approvals and turn-complete on a frozen phone are better with Pushover (PUSHOVER_KEY / PUSHOVER_TOKEN on the daemon — never in YAML).
